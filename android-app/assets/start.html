漫画翻译

打开漫画网站，用 AI 把图片里的文字翻译出来。

上次看到这里：
  1. 第一次用：点右上角「菜单」→「AI 设置」，填上你的 API Key（只需要一次）。
  2. 打开漫画网站，翻到有图片的页面。
  3. 点屏幕右侧悬浮的「译」： 「翻译屏幕上的图片」只翻当前看到的；「自动翻译本网站」开启后滚动到哪翻到哪。
    有些网站的漫画读不到内容：这时 App 会自动改成截屏翻译整个屏幕，翻页后旧译文自动消失；开着「自动翻译」的话，新的一页停稳后会自动翻译。
    如果某个网站自动翻译不正常，开着自动时点一次「翻译整个屏幕」，这个网站以后就固定用整屏方式。
  4. 第一次用建议先点「译」→「设置」→「测试」，看到「成功」再开始看。
  5. 常看的网站可以点「菜单」→「收藏本页」。
每翻译一张图会调用一次 AI，用的是你自己 Key 的额度。读不到内容的图片，App 会改用截屏的方式翻译屏幕上看得见的部分。
