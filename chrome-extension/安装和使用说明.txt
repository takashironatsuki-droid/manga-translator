漫画图片翻译 (AI) —— 安装和使用说明
========================================

一、安装到 Chrome（约 1 分钟）

1. 把这个压缩包解压到一个固定的位置（比如「文档」里）。
   注意：安装后不要删除或移动这个文件夹，否则插件会失效。
2. 打开 Chrome，在地址栏输入  chrome://extensions  然后回车。
3. 打开页面右上角的「开发者模式」开关。
4. 点左上角的「加载已解压的扩展程序」，选择解压出来的 manga-translator 文件夹
   （就是里面直接能看到 manifest.json 的那个文件夹）。
5. 安装成功后会自动弹出设置页面。
   建议点 Chrome 右上角的拼图图标，把「漫画图片翻译」固定到工具栏。


二、连接 AI（只需要做一次）

1. 在设置页选择一家 AI 服务，按提示的链接去申请 API Key。
2. 把 Key 粘贴进去，点「获取模型列表」，选一个支持图片输入的模型。
3. 点「测试」。出现绿色的「成功」就可以用了。

说明：翻译是由你自己的 API Key 调用 AI 完成的，每翻译一张图调用一次，
费用和免费额度以各家 AI 服务官网的说明为准。

用 DeepSeek 的话：
· 「AI 服务」选「DeepSeek」，接口地址和模型（deepseek-flash）会自动填好，
  只需要粘贴 Key，然后点「测试」。
· 模型不要改：DeepSeek 目前只有 deepseek-flash 能看图。
· DeepSeek 没有免费额度，要先在它的网站充值；提示「余额不足（402）」就是该充值了。
· 每家服务的 Key 和模型是分别记住的。从 Gemini 换到 DeepSeek 再换回来，
  原来的 Key 和模型会自动恢复，不用重新粘贴。


三、使用方法

· 鼠标移到漫画图片上，左上角会出现「译」按钮，点一下就翻译这张图。
· 翻译完成后，按钮变成「看原图 / 看译文」，可以来回切换；「重译」可以重新翻译。
· 自动翻译：在一个网站点过一次「译」之后，这个网站后面的图片（包括下一页、下一话）
  滚动到附近时会自动翻译。图片左上角的「自动：开 / 自动：关」按钮可以随时切换，
  或点工具栏的插件图标，取消勾选「在这个网站自动翻译」。
· 在图片上点右键 →「翻译这张图片」也可以。
· 点工具栏的插件图标 →「翻译本页所有图片」可以一次翻译整页
  （图片多的话会比较慢，也会消耗更多额度）。


四、常见问题

· 没有出现「译」按钮：安装前就打开的网页需要刷新一次；图片太小也不会显示
  （可在设置里调小尺寸限制）。
· 译文位置盖歪了：不同模型的定位能力差别很大。可以换一个模型，
  或在设置里把显示方式改成「图上标编号，译文列在图片旁边」。
· 提示「无法直接读取这张图片」：有些网站对图片做了保护。把图片滚动到屏幕中间，
  再单独点它的「译」按钮，插件会改用截图的方式翻译屏幕上可见的部分。
· 提示 Key 无效 / 额度用完 / 模型不支持图片：回到设置页检查 Key，或换一个模型再点「测试」。
· 修改了插件文件后：到 chrome://extensions 点这个插件卡片上的刷新按钮，再刷新网页。


五、从旧版本升级

1. 解压新的压缩包，把里面 manga-translator 文件夹中的所有文件，
   复制到你原来安装用的那个 manga-translator 文件夹里，选择「替换」。
   （一定要放回原来的文件夹，这样之前的 Key 和设置才会保留。）
2. 打开 chrome://extensions ，点这个插件卡片上的圆形箭头（刷新）按钮。
3. 把正在看的漫画网页刷新一次。
