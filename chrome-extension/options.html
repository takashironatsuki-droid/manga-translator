漫画图片翻译 · 设置

所有设置会自动保存，只保存在你自己的浏览器里。

第一步：连接 AI

  1. 选一家 AI 服务，去它的网站申请一个 API Key（一串密码一样的字符）。
  2. 把 Key 粘贴到下面，点「获取模型列表」，选一个支持图片输入的模型（选 DeepSeek 时模型会自动填好，这一步可以跳过）。
  3. 点「测试」，看到绿色提示就可以用了。

必须选能看图的模型（多模态 / vision）。纯文字模型会报错。每家服务的 Key 和模型会分别记住，来回切换不用重新填。

第二步：翻译设置

填了之后，这些语言的文字会保持原样，其他语言照常翻译。

如果你用的模型定位不准、译文盖错了地方，换成第二种更好读。

其他

开启自动的网站会被记住，下一话、下一页也会自动翻译。想关掉时，点图片上的「自动：开」按钮，或点插件图标取消勾选。

免费的 Key 每分钟次数有限，超过就会报"请求太频繁"。数字越小越不容易报错，但自动翻译会排队更久。付费的 Key 可以填 0。
